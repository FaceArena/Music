# Kimo

Kimo is a music player focused on a fluid, touch-first listening experience.

## Development

The application foundation is being set up with React, TypeScript and Vite. See the project scripts once dependencies are installed.

## Product principles

- Preserve the approved Figma design as the visual source of truth.
- Keep playback logic independent from the interface.
- Use only audio sources that permit playback in a third-party application.
- Treat imported playlists as metadata until each track is matched to a playable, authorized source.
